## Automated rule-script note

The repository skill's `audit_rules.js` reports 100/100 for 16 of 17 indexable non-home pages and 90/100 for the home page. The home result is a false negative: its H1 contains an `<em>` element, while the script only recognizes H1 text without nested markup. Browser DOM inspection and the site validator both confirm exactly one H1. The 404 score is excluded because it is intentionally non-indexable.

## Standards decisions

- No `meta keywords` tag was added because Google states that it is not used for indexing or ranking.
- Evergreen walkthrough titles were not given artificial month markers. Dates should be used only when the page content is actually time-sensitive and maintained accordingly.
- FAQ schema was not fabricated. Google limits regular FAQ rich results to authoritative government and health sites, and these pages do not contain reviewed five-question FAQ sections.
